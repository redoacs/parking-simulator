# v1.2 PR 1 — WebGL2 replaces WebGPU: Implementation Plan

> **For agentic workers:** executed inline by the plan's author in the session that wrote it (superpowers:executing-plans), then independently reviewed. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the WebGPU renderer with a WebGL2 one behind the unchanged `Renderer` surface, with no visible change.

**Architecture:** `src/render/gpu.ts` becomes `src/render/gl.ts` (context, program compilation, camera uniform block). Each pipeline file keeps its name and role and swaps GPU objects for GL ones. `App`, `Camera`, `scenePolys`, the pure envelope helpers and every unit test are untouched.

**Tech Stack:** TypeScript, Vite (`?raw` shader imports), WebGL2 / GLSL ES 3.00, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-19-v1.2-webgl2-vertical-responsive-design.md` (§ PR 1).

**Deliberate departure from the plan template:** the port is a mechanical translation of ~650 existing lines, written and executed by the same author. The plan fixes the file map, interfaces, translation rules and every GL-specific decision, and gives new test code in full; it does not restate all translated code verbatim.

## Global Constraints

- `Renderer` public surface is unchanged: `create`, `camera`, `resize`, `frame(FrameInput)`, `resetEnvelope`, `rebuildEnvelope`, `readEnvelopeAt`. `renderer.device` is removed; `renderer.onContextLost(cb: (message: string) => void)` replaces `main.ts`'s use of `device.lost`.
- Context: `canvas.getContext('webgl2', { alpha: false, antialias: false })`.
- Draw order unchanged: grid, static polygons, envelope, rings, dynamic polygons; clear colour `(0.078, 0.09, 0.11, 1)`.
- Context-loss policy unchanged: `decideOnDeviceLoss` reloads once per session, otherwise shows the message.
- No pixel-equality claim between the two APIs.
- SwiftShader flags and CI Vulkan packages are removed only if e2e is observed passing without them.
- Gates on every commit: `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm test`; `pnpm test:e2e` at the end of each task.

## Translation rules (apply to all four shaders)

One `.glsl` file holds both stages. `compileProgram` compiles it twice, prefixing
`#version 300 es\n#define VERTEX\n` or `#version 300 es\n#define FRAGMENT\nprecision highp float;\n`
(`#version` must be the first line, so the file itself never contains it).

```glsl
// poly.glsl — complete file; the other three follow this shape
layout(std140) uniform Camera {
  vec2 scale;
  vec2 offset;
  vec2 viewport;
  vec2 pad;
} cam;

#ifdef VERTEX
layout(location = 0) in vec2 aPos;
layout(location = 1) in vec4 aColor;
out vec4 vColor;
void main() {
  gl_Position = vec4(aPos * cam.scale + cam.offset, 0.0, 1.0);
  vColor = aColor;
}
#endif

#ifdef FRAGMENT
in vec4 vColor;
out vec4 outColor;
void main() {
  outColor = vec4(vColor.rgb * vColor.a, vColor.a); // premultiplied
}
#endif
```

- `@builtin(vertex_index)` → `gl_VertexID`; constant corner arrays become `const vec2 CORNERS[6] = vec2[6](...)`.
- `vec2f/vec4f/f32` → `vec2/vec4/float`; `let` → typed locals; `textureSample(tex, samp, uv)` → `texture(uTex, uv)`.
- std140: four `vec2` pack at offsets 0/8/16/24 (32 bytes) and `vec2, vec2, vec4` at 0/8/16 (32 bytes), so `Camera.uniformData()` and the envelope uniform upload byte-for-byte as today.
- Every program binds block `Camera` to binding 0 (`uniformBlockBinding`); the envelope program binds `Envelope` to binding 1. `bindBufferBase(UNIFORM_BUFFER, 0, …)` selects the screen camera or the envelope's accumulation camera.

## GL decisions

- **Blending.** Screen draws: `blendFunc(ONE, ONE_MINUS_SRC_ALPHA)`, `blendEquation(FUNC_ADD)` (premultiplied, as today). Grid: blending off. Envelope accumulation: `blendEquation(MAX)` (factors are ignored for MAX). Each `draw` sets the blend state it needs; nothing relies on leftover state.
- **Buffers.** `bufferData(ARRAY_BUFFER, data, DYNAMIC_DRAW)` on every upload. The buffer object never changes, so each batch's VAO stays valid and today's grow-and-recreate logic goes away. Ring instance attributes use `vertexAttribDivisor(loc, 1)` and `drawArraysInstanced(TRIANGLES, 0, 6, count)`.
- **Envelope texture.** `texStorage2D(TEXTURE_2D, 1, R8, w, h)`, `LINEAR` min/mag, `CLAMP_TO_EDGE`, attached to a framebuffer; `checkFramebufferStatus` must be `FRAMEBUFFER_COMPLETE` or `setBounds` throws. Size clamps to `gl.getParameter(MAX_TEXTURE_SIZE)`. Clearing = bind framebuffer, `clearColor(0,0,0,0)`, `clear`. After any framebuffer pass: rebind `null` and restore the canvas viewport.
- **Orientation (the trap).** WebGPU's row 0 is the top of the target; GL's row 0 is the bottom. Therefore:
  - composite shader uses `vUv = c` (no `1.0 - c.y` flip);
  - `readAt` keeps `envelopeTexel` (top-left convention, unit-tested, unchanged) and reads at `y = height - 1 - t.y`;
  - `readPixels(x, y, 1, 1, RGBA, UNSIGNED_BYTE, out)` and return `out[0] / 255`. `readAt` stays `async`.
- **Context loss.** `canvas.addEventListener('webglcontextlost', e => { e.preventDefault(); cb('WebGL context lost'); })`. `main.ts` keeps the `decideOnDeviceLoss` branch as is.
- **No WebGL2.** `initGl` throws `WebGlUnavailableError('This browser has no WebGL2.')` when `getContext` returns null. `main.ts` appends: "Requires a browser with WebGL2: any current Chrome, Edge, Firefox or Safari."

```ts
worldToCss(p: Vec2): Vec2 {
  const clipX = (p.x - this.cx) * this.scaleX();
  const clipY = (p.y - this.cy) * this.scaleY();
  return { x: (((clipX + 1) / 2) * this.widthPx) / this.dpr, y: (((1 - clipY) / 2) * this.heightPx) / this.dpr };
}
```

```ts
// The envelope must also be DRAWN where the car has been. The texture read-back above cannot see a vertically
// mirrored composite; the screen can. Compare a swept point the car has left with its mirror image across the
// lane centre-line, which the car never touched.
const nose = { x: start.state.x + 3.3, y: start.state.y }; // just behind the front bumper at the start pose
const mirrorY = 2 * start.state.y - nose.y + 1.4; // 1.4 m to the other side of the start line, still road
const px = async (wx: number, wy: number): Promise<number[]> => {
  const css = await page.evaluate(([x, y]) => window.__sim!.worldToCss(x, y), [wx, wy] as const);
  const shot = await page.locator('#gpu').screenshot({ clip: undefined });
  return page.evaluate(
    async ([b64, cx, cy]) => {
      const img = new Image();
      img.src = `data:image/png;base64,${b64}`;
      await img.decode();
      const c = document.createElement('canvas');
      c.width = img.width;
      c.height = img.height;
      const g = c.getContext('2d')!;
      g.drawImage(img, 0, 0);
      const k = img.width / document.getElementById('gpu')!.clientWidth;
      return [...g.getImageData(Math.round(cx * k), Math.round(cy * k), 1, 1).data];
    },
    [shot.toString('base64'), css.x, css.y] as const,
  );
};
const swept = await px(nose.x, nose.y);
const untouched = await px(nose.x, mirrorY);
const delta = Math.max(...swept.slice(0, 3).map((v, i) => Math.abs(v - untouched[i]!)));
expect(delta, `swept ${swept} vs untouched ${untouched}`).toBeGreaterThan(12);
```
