# v1.2 PR 3 — Responsive layout and touch: Implementation Plan

> **For agentic workers:** executed inline by the plan's author, then independently reviewed. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make the simulator usable on a phone: scene fills the screen, split-thumb drive controls, settings in a sheet, pinch-zoom.

**Architecture:** One DOM, two layouts chosen by CSS. A new `src/ui/overlay.ts` builds the on-scene controls and reuses `DriveInput.bind`. `Camera` gains one pure gesture method; `App` tracks active pointers and calls it.

**Tech Stack:** TypeScript, CSS media queries, Pointer Events, Playwright (phone emulation + CDP multi-touch).

**Spec:** `docs/superpowers/specs/2026-09-19-v1.2-webgl2-vertical-responsive-design.md` (§ PR 3).

## Global Constraints

- Wide layout (≥ 900 px **and** a fine pointer) is unchanged. Everything else gets the compact layout: `@media (max-width: 899px), (pointer: coarse)`.
- The sheet is the existing `#panel`, moved by CSS. No second panel, no duplicated inputs.
- Overlay buttons use `DriveInput.bind` (already per-pointer). A pointer that goes down on a button never pans.
- Touch targets ≥ 48 px. Supported width 320 px and up, portrait and landscape.
- `viewport-fit=cover` + `env(safe-area-inset-*)`; `100dvh` with a `100%` fallback; no text selection, callout or context menu on the controls.
- Gates on every commit: typecheck, lint, format:check, unit tests; e2e (on a private `E2E_PORT`) at the end of each task.

### Task 1: pinch gesture maths (TDD)

- [ ] Failing tests in `camera.test.ts`: (a) fingers moving apart about a fixed midpoint zoom by the distance ratio and keep the world point under the midpoint fixed; (b) both fingers translating together pans without zooming; (c) the world points under each finger stay under that finger for a pure spread; (d) coincident previous points (distance 0) do not produce `NaN`/`Infinity`.
- [ ] Implement:

```ts
pinchCss(prevA: Vec2, prevB: Vec2, a: Vec2, b: Vec2): void {
  const prevDist = Math.hypot(prevB.x - prevA.x, prevB.y - prevA.y);
  const dist = Math.hypot(b.x - a.x, b.y - a.y);
  const prevMid = { x: (prevA.x + prevB.x) / 2, y: (prevA.y + prevB.y) / 2 };
  const mid = { x: (a.x + b.x) / 2, y: (a.y + b.y) / 2 };
  if (prevDist > 0 && dist > 0) this.zoomAtCss(prevMid.x, prevMid.y, dist / prevDist);
  this.panByCss(mid.x - prevMid.x, mid.y - prevMid.y);
}
```

- [ ] `App.attachCameraControls`: `Map<pointerId, Vec2>` in canvas-relative CSS px. `pointerdown` adds (max two), `pointermove` with one pointer pans, with two calls `pinchCss` using the stored and new positions, `pointerup`/`pointercancel` removes. Commit.
