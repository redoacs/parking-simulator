# English and Spanish interface retrospective

2026-09-20. Slice: [PR #9](https://github.com/redoacs/parking-simulator/pull/9), branch `i18n-en-es`, base `b6c7154`.

## Result and design decisions

The UI supports English and Mexican Spanish with saved-choice/browser-language/English fallback, immediate switching, localized source explanations and known error summaries. Physics, scenario hashes and numeric input values remain locale independent. A switch updates text and attributes in place, preserving run history, camera and held-control DOM identities.

Root initially recommended i18next. The informed Fable design lane challenged whether its plural/fallback machinery had a current consumer. Root enumerated the measurement-oriented messages and removed the provisional dependency. Typed complete catalogs, named-argument message functions and native number formatting meet the present scope. A third language requires the documented catalog/registration/selector/document-language changes; no framework migration was added.

Confidence previously depended on an English note prefix. Both lanes agreed it belongs in explicit validated metadata. Fable caught the redundant prefix after the first design disposition and proposed reusing already-Spanish source snippets plus a numerical-token guard. Root removed the prefix, reused canonical snippets and added that guard. Source explanations and US-sheet labels are translated; this does not preserve every original quote literally. The guard preserves numeric tokens, not translation semantics.

Recorded design disagreements: root retained the catalog's canonical JSON imports with vehicle-qualified keys and a supplied-note fallback for other accepted vehicle IDs. Fable preferred a separate Spanish overlay fed by the validated spec but accepted the one-vehicle implementation. The design lane withdrew its claims that grouping would contradict the source and that a quote/explanation schema was the only solution; it also accepted root's typed scene IDs in place of its proposed coverage test. Root also retained cached Intl formatting after review questioned its current output similarity: locale-specific display formatting was accepted scope. Neither disagreement is an unresolved shipping blocker.

## Validation and limits

At implementation head `e0ea685`, all required commands passed: `pnpm test` (257 tests), `pnpm build`, `pnpm lint`, `pnpm format:check`, `pnpm test:e2e` (51 tests: 23 Chromium, 14 Firefox, 14 WebKit). These are root-executed results, taken on trust by the read-only peer. Tests include switching without state/DOM replacement, preference persistence, denied storage, translated errors, source confidence, numeric edits and narrow layout. The locally provisioned WebKit library/runtime was reused; no system package was installed during this milestone.

The design consensus pass also noted that at 320 pixels some uncertainty badges and `10.70 m` wrap mid-phrase or before the unit. All remain visible; improving this compact table is a cosmetic follow-up. The numerical-token test is tautological for the four reused snippets and checks numeric preservation, not semantic accuracy, in the translated notes.

No physical phone, real GPU reset, screen reader or speech-input tool was tested. Synthetic GPU-loss events test handler behavior only. Hover source notes remain poorly discoverable on touch. Spanish translation correctness is human source review, not something catalog typing or numeric parity proves. Current translated vehicle-note coverage is the bundled Taos only. All five local gates also passed at closeout head `85af9e8` with the same test counts. The PR carries final hosted checks and the bounded closeout delta verdict before merging.
